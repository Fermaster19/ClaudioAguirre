## 💻 Proyectos destacados

### 🔹 AutoQuote MVP

Sistema de automatización para la generación de presupuestos comerciales mediante inteligencia artificial.

- Extracción automática de información.
- Revisión y edición de presupuestos.
- Generación de PDF.
- Integración con Gmail y Google Sheets.

**Tecnologías:** React, Node.js, n8n, Google Gemini y APIs de Google.

[📂 Ver repositorio](https://github.com/Fermaster19/-AutoQuote_MVP)

### 🔹 Manos Conectadas

Plataforma web para registrar, administrar y realizar el seguimiento de donaciones solidarias.

- Registro de donaciones.
- Gestión administrativa.
- Seguimiento mediante códigos.
- Asistentes de inteligencia artificial.

**Tecnologías:** HTML, CSS, JavaScript, Supabase, PostgreSQL, Vercel y Groq.

[📂 Ver repositorio](https://github.com/Fermaster19/ManosConectadas)
[🌐 Ver proyecto](https://manos-conectadas-utxp.vercel.app)
